## How I work

Most problems arrive looking like one thing and turn out to be another. A conversion problem is usually a customer experience problem. A support-volume problem is usually a product gap.

- **Start with the customer, end with the metric.** Every roadmap item traces back to a customer need and forward to a measurable outcome.
- **Diagnose first, then build.** The first explanation is often a symptom, not the cause.
- **Ship AI in stages.** Earn customer trust first, then add autonomy.
- **Every experiment teaches something.** A losing test with a clear hypothesis beats a winning one nobody can explain.
